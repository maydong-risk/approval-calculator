> 金融机构风控视角下的审批测算最小示意 demo。
> 把「电动重卡风控手记」系列文章里的风控原理，做成一个能动手试的工具。

---

## 先读这个（边界声明）

这是一个**金融机构风控**的审批测算演示，不是卖车口径的 TCO 计算器。上手前先对齐三点，避免理解偏差：

1. **风控口径 ≠ 卖车口径**。这里的 TCO 按「融资期限内的持有成本」算，上限 3 年（跟着融资期限走）。卖车常用的「8 年全生命周期」是营销口径，不在本框架内——放款机构不可能把资金放到残值崩盘之后才收。

2. **数据全是示意估算值**。页面里的车型价、电量、残值率、电价、融资基准，都是为演示方法论而设的参考默认值，不是真实报价，也没有任何报价或放款入口。

3. **这是大致示意、并不完善**。只覆盖风控方法论的主干变量，没穷尽所有场景。数值请勿对号入座。

## 这是什么

一套把「道」落成「器」的最小演示：系列文章一直在讲「风控怎么想」，这个 demo 让你**自己动手试**，验证那些原理怎么落地。

一条线走完：

- 车型配置（7 品牌 × 14 款，含电量区间估算价）
- 融资方案（首付 / 保证金 / 利率 / 期限）
- TCO（3 年持有口径，与贷款期限解耦）
- DSCR（按实际贷款期限算月供，永远看最大风险）
- 残值敞口（首付 + 保证金兜底）
- 交叉点（残值线与本金线何时相交）
- 审批判定（DSCR ≥ 1.30 + 省的幅度 ≥ 20%）

## 能亲手验证哪些机制

改一个数，看右边的结果怎么跟着动：

- **动首付** → 交叉点前移甚至消失（首付是压敞口的「手术刀」）
- **动期限** → 月供变大、DSCR 往下掉（期限被残值不确定锁在 3 年内）
- **动保证金** → 月供纹丝不动、但实际年化 IRR 往上爬（保证金不冲本金、锁现金、抬资方实际收益）
- **动电价 / 渠道占比** → TCO 变（谷平峰 + 自有桩/公共桩/高速三渠道加权）
- **换品牌 / 车型** → 残值档变 → 敞口变（品牌决定残值的地板）

## 怎么用

两个页面：

- **配置页**：先设定车型矩阵、残值档参数、电价三档、融资基准（金融机构完成偏好设定）。
- **决策页**：填单车的车辆 / 融资 / 收入（含计费方式与吨公里参数）/ 能源 / 运营成本，右侧实时出结果。

浏览器打开 `index.html` 即可，无需安装、无后端依赖，纯单文件。
